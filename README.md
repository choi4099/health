# 헬스 – 카메라 자세 분석 안드로이드 앱

카메라로 사람의 관절을 인식해 헬스 동작의 자세를 **손 / 팔 / 다리 / 몸** 부위별 점수와 **종합 점수**로 보여 주고,
**문제점**과 **개선 방법**을 알려 주는 앱입니다. 앱 아이콘 이름은 **"헬스"** 입니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 동작 목록 | 107개 (상체 49 · 하체 25 · 코어 15 · 전신 18), 부위별 분류 · 난이도(초급/중급/고급) 필터 · 검색 |
| 동작 상세 | 주동근/보조근, 근육 발달 효과 설명, 촬영 방향(정면/옆면/뒷면), 기준 자세 그림, 평가 항목 |
| 자세 겹쳐 보기 | 카메라 화면 위에 사용자 뼈대(점수별 색)와 기준 자세(흰색 반투명)를 겹쳐 표시. 골반 위치와 몸통 길이에 맞춰 크기와 좌우 방향을 자동으로 맞춤 |
| 점수 | 실시간 종합 점수 + 손·팔·다리·몸 점수, 5초 측정 후 결과 화면 |
| 피드백 | 각 문제점(측정 각도 vs 목표 각도)과 구체적인 개선 방법 |
| 설치/삭제 | 앱 안: APK 선택 설치(업데이트), 앱 삭제 버튼 / PC: `scripts/` 의 설치·삭제 스크립트 |

## 빌드 및 설치

필요한 것: Android Studio (Ladybug 이상) 또는 JDK 17 + Android SDK 35, 안드로이드 8.0(API 26) 이상 휴대폰

1. 휴대폰 **설정 → 개발자 옵션 → USB 디버깅** 켜기 후 PC에 USB 연결
2. 방법 A – Android Studio: 이 폴더를 열고 ▶ Run
3. 방법 B – 스크립트
   - Windows: `scripts\install.bat` 더블클릭 (빌드 + 설치 + 실행)
   - macOS/Linux: `./scripts/install.sh`
4. 삭제: `scripts\uninstall.bat` / `./scripts/uninstall.sh`, 또는 앱의 **설정 → 앱 삭제**

> 처음 빌드할 때 Gradle·라이브러리를 인터넷에서 내려받으므로 몇 분 걸립니다.
> `adb`는 Android SDK의 `platform-tools` 폴더에 있습니다 (PATH에 추가 필요).

## GitHub에서 APK 받기 (PC에 개발 도구 없이)

1. GitHub에서 새 저장소를 만들고 이 폴더 전체를 올립니다 (`.github` 폴더 포함).
2. 올리면 **Actions** 탭에서 "APK 빌드"가 자동으로 실행됩니다 (약 5~10분).
3. 완료된 실행을 열고 맨 아래 **Artifacts → health-apk** 를 내려받아 압축을 풉니다.
4. `app-debug.apk` 를 휴대폰으로 옮겨 실행하면 설치됩니다 ("출처를 알 수 없는 앱 설치" 허용 필요).

## 사용 방법

1. 목록에서 동작 선택 → **카메라로 자세 체크**
2. 안내된 방향(정면/옆면/뒷면)으로 서서 몸 전체가 화면에 들어오게 2~3m 떨어지기
3. 흰색 기준 자세에 맞춰 자세를 잡고 **측정 시작** → 3초 카운트다운 후 5초 측정
4. 결과 화면에서 부위별 점수, 문제점, 개선 방법 확인

## 점수 계산 방식

- 동작마다 "가장 중요한 순간(예: 스쿼트 최저점)"의 목표 관절 각도와 허용 오차를 정의했습니다.
- 항목 점수: 오차가 허용 범위 안이면 100점, 허용 오차의 3배에서 0점 (선형 감소)
- 부위 점수: 그 부위 항목들의 평균 (항목이 없으면 "해당 없음")
- 종합 점수: 팔 30% · 다리 30% · 몸 30% · 손 10% 가중 평균 (해당 없는 부위는 제외하고 재계산)
- 85점 미만인 항목은 문제점과 개선 방법으로 표시합니다.
- 화면에 잘 보이지 않는 관절(인식 신뢰도 50% 미만)이 포함된 항목은 점수에서 제외합니다.

## 코드 구조

```
app/src/main/java/com/health/posecoach/
├─ MainActivity.kt              화면 이동(목록→상세→카메라→결과, 설정)
├─ data/
│  ├─ Exercise.kt               동작 모델(분류·난이도·근육·설명)
│  └─ ExerciseRepository.kt     107개 동작 데이터
├─ pose/
│  ├─ PoseModel.kt              관절, 부위, 촬영 방향, 각도 계산
│  ├─ PoseTemplates.kt          67개 동작 패턴의 기준 자세 + 평가 규칙
│  ├─ PoseScorer.kt             규칙 평가 → 부위/종합 점수, 문제점, 개선 방법
│  └─ PoseAnalyzer.kt           CameraX 프레임 → ML Kit 포즈 인식
├─ ui/                          Compose 화면 (목록, 상세, 카메라, 결과, 설정)
└─ install/AppInstaller.kt      앱 안 APK 설치 / 앱 삭제
```

### 동작 추가·수정 방법
- 새 동작: `ExerciseRepository.kt` 에 `x(분류, "세부분류", "이름", 난이도, "주동근", "보조근", "설명", 템플릿ID)` 한 줄 추가
- 기준 각도 조정: `PoseTemplates.kt` 에서 해당 템플릿의 `knee(목표, 허용오차, "부족할 때 조언", "과할 때 조언")` 등 숫자 수정
- 기준 자세 그림: `Ref.side(...)` / `Ref.front(...)` 의 마디 방향 각도(0°=위, 90°=앞, 180°=아래)

## 알아 둘 점

- 카메라 2D 인식이라 각도는 근사치입니다. 안내된 촬영 방향을 지키면 정확도가 크게 올라갑니다.
- 슈러그(어깨 으쓱)처럼 관절 각도 변화가 작은 동작은 팔 자세와 좌우 균형 위주로 평가합니다.
- 버피·맨 메이커 같은 복합 동작은 대표 구간(플랭크)만 평가합니다.
- 앱 안 APK 설치 기능은 개인 설치용입니다. Google Play 에 올릴 경우 `REQUEST_INSTALL_PACKAGES` 권한은 정책상 제거해야 할 수 있습니다.
